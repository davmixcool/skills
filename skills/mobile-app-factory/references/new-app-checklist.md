# New App Checklist

Use this every time you create a new factory app.

## 1. Problem

- [ ] Define the responsibility the app owns
- [ ] Define the consequence of forgetting
- [ ] Define the target user narrowly
- [ ] Explain why Calendar/Reminders is insufficient
- [ ] Score idea using `APP_IDEA_SCORECARD.md`

## 2. Positioning

- [ ] Write one-line promise
- [ ] Write 5 short ad hooks
- [ ] Define the first paid outcome
- [ ] Choose a clear category/search term

## 3. Domain model

- [ ] Define tracked entity
- [ ] Define event types
- [ ] Define default schedules
- [ ] Define default reminder offsets
- [ ] Define completion actions
- [ ] Define recurring behavior

## 4. V1 scope

- [ ] Onboarding
- [ ] Add entity
- [ ] Suggested events
- [ ] Reminder schedule
- [ ] Notification actions
- [ ] Timeline/history
- [ ] Paywall
- [ ] Settings
- [ ] Analytics

## 5. Monetization

- [ ] Define free limit
- [ ] Define premium features
- [ ] Set annual price
- [ ] Decide monthly option
- [ ] Decide trial/no-trial
- [ ] Define paywall trigger

## 6. Reliability

- [ ] Notification permission flow tested
- [ ] Background/OS behavior tested
- [ ] Restart tested
- [ ] Timezone handling tested
- [ ] Reconciliation tested
- [ ] Restore purchases tested

## 7. Store assets

- [ ] Name
- [ ] Icon
- [ ] Subtitle
- [ ] Screenshots
- [ ] Description
- [ ] Privacy policy
- [ ] Terms
- [ ] Support contact

## 8. Launch

- [ ] Analytics dashboard ready
- [ ] Test users onboarded
- [ ] 3 ad creatives ready
- [ ] ASO keywords documented
- [ ] Landing page live
- [ ] App Store submitted
- [ ] Play Store submitted

## 9. Post-launch decision

At 30–60 days, decide:
- [ ] Kill
- [ ] Maintain
- [ ] Grow
- [ ] Graduate into larger product
